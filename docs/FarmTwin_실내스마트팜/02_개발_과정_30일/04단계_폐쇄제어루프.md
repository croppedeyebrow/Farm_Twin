# 4단계 — 규칙 엔진과 폐쇄 제어 루프

## 기간

Day 12~15

## 목표

인식 → 판단 → 명령 → 적용 → 상태 변화 → 재관측이 자동 순환하도록 한다.

## 작업

### Day 12

- [ ] 규칙 schema와 version
- [ ] 조건 연산자와 우선순위
- [ ] 품질 불량 측정 처리 정책

### Day 13

- [ ] HVAC, fan, dehumidifier 액추에이터
- [ ] irrigation, LED 액추에이터
- [ ] command와 event 분리

### Day 14

- [ ] start/stop 임계값

- [ ] 자동/수동 모드
- [ ] command idempotency

### Day 15

- [ ] 온도 폐쇄 루프 통합 테스트
- [ ] 배지수분 폐쇄 루프 통합 테스트
- [ ] 충돌·채터링·중복 명령 테스트

## 필수 증거

```text
온도 상승 → 냉방 명령 → 가상 냉방기 작동
→ 온도 하락 → 종료 임계값 → 냉방 정지
```
