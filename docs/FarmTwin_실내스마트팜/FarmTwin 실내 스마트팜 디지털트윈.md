# FarmTwin 실내 스마트팜 디지털트윈

## 프로젝트 한 줄 설명

가상 센서와 가상 설비로 실내 재배환경을 생성하고, 실시간 관제·규칙 제어·부하테스트를 통해 폐쇄 제어 루프를 검증하는 소프트웨어 기반 운영 트윈.

## 개발 기준선

- 실제 스마트팜 장비와 기상센서는 사용하지 않는다.
- 외기 온·습도는 `API`, `REPLAY`, `SYNTHETIC` 모드를 지원한다.
- 실내 온도·습도·CO₂·배지수분·PPFD는 Python 시뮬레이터가 생성한다.
- 냉난방기·환기팬·제습기·관수펌프·LED는 가상 액추에이터다.
- 제어 명령은 반드시 다음 환경 상태에 영향을 주어야 한다.
- 기능 시뮬레이션과 대량 부하 생성은 분리한다.
- 30일 안에 공개 배포와 데모 영상을 완성한다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Three.js/R3F, ECharts |
| API | Python, FastAPI, Pydantic, SQLAlchemy |
| 시뮬레이터 | Python, asyncio |
| 데이터베이스 | PostgreSQL, PostGIS |
| 실시간 | WebSocket |

| 인프라 | Docker Compose, Nginx, GitHub Actions, Cloud |
| 관측성 | 구조화 로그, Prometheus, Grafana |

## 문서 사용 순서

1. `01_종합_기획_문서`에서 각 영역의 목표 구조를 이해한다.
2. `02_개발_과정_30일`의 단계를 순서대로 수행한다.
3. 각 단계의 완료 기준을 통과하기 전 다음 단계로 넘어가지 않는다.
4. 범위가 늘어나면 MVP 제외 목록과 30일 일정부터 다시 검토한다.

2. 가상 센서 데이터 스트리밍
