# 시간 컬럼 의미

2단계 Day 5에서 확정한 정의다. 코드의 `app/domain/time_semantics.py` 와 동일해야 한다.

## 핵심 구분

| 컬럼 | 시계 | 의미 |
|---|---|---|
| `simulation_time` | 가상 | 시뮬레이터 내부 시계(초). 상태전이·샘플·규칙 판정의 **기준 시각** |
| `sampled_at` | wall / 원본 | 소스에서 값이 샘플링된 시각 |
| `ingested_at` | wall | FarmTwin 이 적재한 시각 (지연·stale 판정) |
| `created_at` / `updated_at` | wall | 메타데이터 행 감사 시각 |
| `started_at` / `ended_at` | wall | SimulationRun 실행 구간 |
| `worker_heartbeat_at` | wall | simulator worker lease 갱신 |

## 불변조건

1. `sensor_readings` 원본은 수정하지 않는다. 보정값은 별도 컬럼/테이블로 확장한다.
2. `FarmState.version` 은 단조 증가한다.
3. 실시간 WebSocket 발행은 DB commit 성공 **이후** 수행한다.
4. `sampled_at` 과 `ingested_at` 을 같은 의미로 쓰지 않는다.
5. 차트·이력 API 의 기본 정렬 키는 `simulation_time` (필요 시 `sampled_at`).

## 테이블별 사용

### `simulation_runs`

- `simulation_time_seconds`: 현재 가상 시계
- `started_at` / `ended_at`: 운영 wall-clock 구간
- `worker_heartbeat_at`: active worker 생존

### `weather_snapshots` / `sensor_readings`

- `simulation_time`, `sampled_at`, `ingested_at` 세 컬럼을 모두 저장
- `(simulation_run_id, sequence)` UNIQUE

### `farm_states`

- room 당 1행 (현재 참값)
- `simulation_time`: 이 참값이 계산된 가상 시각
- `updated_at`: 행이 갱신된 wall-clock

## 참값 vs 측정값

- **참값** (`farm_states`): 환경 모델이 계산한 내부 상태
- **측정값** (`sensor_readings`): 가상 센서가 관측한 값 (노이즈·고장·품질 포함)

둘을 한 테이블에 합치지 않는다.
