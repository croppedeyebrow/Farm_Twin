# 데이터 사전 — 2단계

시간 컬럼 상세는 [시간_컬럼_의미.md](./시간_컬럼_의미.md) 를 본다.

## 계층

| 테이블 | 컬럼 | 설명 |
|---|---|---|
| sites | id | PK |
| sites | name | 사이트 이름 |
| sites | location | `geography(Point,4326)` |
| farms | site_id | FK → sites |
| farms | code | site 내 unique |
| rooms | farm_id | FK → farms |
| rooms | code | farm 내 unique |
| racks | room_id | FK → rooms |
| racks | position_* | 3D 로컬 좌표(선택) |

## 설비

| 테이블 | 컬럼 | 설명 |
|---|---|---|
| sensors | sensor_type | temperature/humidity/co2/substrate_moisture/ppfd |
| sensors | unit | 정규화 단위 |
| sensors | model_version | 센서 모델 lineage |
| sensors | rack_id | null 이면 룸 공용 |
| actuators | actuator_type | hvac/fan/dehumidifier/irrigation/led |
| actuators | mode | off/on/auto |
| actuators | output_ratio | 0~1 |

## 텔레메트리

| 테이블 | 컬럼 | 설명 |
|---|---|---|
| farm_states | version | 단조 증가, room 당 1행 |
| farm_states | *_c / *_pct / *_ppm / ppfd | **참값** |
| sensor_readings | sequence | run 내 unique (서버 발급 저장 순번) |
| sensor_readings | source_sequence | 센서 스트림 번호 — (run, sensor) 내 unique, 중복·누락 판정 기준 |
| sensor_readings | value/unit/quality/source | **측정값** — quality=missing 누락 마커만 value/raw_value NULL |
| sensor_readings | quality_reason | 품질 사유 코드 (`;` 로 여러 개, 예: `sequence_gap;rate_of_change_exceeded`) |
| sensor_readings | simulation_time/sampled_at/ingested_at | 시간 삼중 컬럼 |
| simulation_runs | random_seed | 재현성 |
| simulation_runs | weather_mode | API/REPLAY/SYNTHETIC |
| simulation_runs | rule_set_version | 활성 규칙 묶음 지문 `rules.v1:<sha12>` (판정 필드만) |
| simulation_runs | initial_state | 첫 step 직전 체크포인트 (참값·설비·스트림 판정 상태·송신 커서·게이트·차단) |
| simulation_runs | replay_of_run_id / replay_input | 재생 run 의 원본 run, 외기·스텝·수동 제어 일정·기대 결과 |
| weather_snapshots | outdoor_* | 외기 입력 (step 마다 1행, run 내 sequence) |

## 제어·고장

| 테이블 | 컬럼 | 설명 |
|---|---|---|
| control_rules | start/stop_threshold | 히스테리시스 |
| control_rules | version | 규칙 변경 시 증가 |
| control_commands | idempotency_key | 중복 명령 차단 |
| control_commands | desired_* | 목표 (결과 아님) |
| control_commands | rule_version | 명령 당시 규칙 개정 번호 (수동 명령은 NULL) |
| control_commands | trigger_reading_id | 판정 근거 측정 행 (dropout·수동이면 NULL) |
| control_commands | reason=manual | 운영자 수동 제어 (rule_id NULL) |
| control_events | event_type | applied/stopped/failed/rejected |
| fault_injections | fault_type | spike/stuck/dropout |
| fault_injections | active | 진행 중 여부 |
